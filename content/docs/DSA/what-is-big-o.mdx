## Big O Runtime Comparison (The 5 Fundamental Curves)

The five foundational Big O growth rates seen across data structures and algorithms:

| Complexity | Name | Performance | Growth Behavior |
| :--- | :--- | :--- | :--- |
| **O(1)** | Constant Time | Ideal / Best | Completely flat line; unaffected by input size. |
| **O(log n)** | Logarithmic Time | Excellent | Slowly rises then flattens; halves problem space each step. |
| **O(n)** | Linear Time | Fair / Good | Straight diagonal line; operations grow 1-to-1 with input. |
| **O(n^2)** | Quadratic Time | Poor | Upward parabola; nested loops over the data. |
| **O(2^n)** | Exponential Time | Horrible / Worst | Nearly vertical rocket; operations double with every +1 input. |
